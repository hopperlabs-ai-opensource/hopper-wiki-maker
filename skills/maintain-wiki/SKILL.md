---
name: maintain-wiki
description: Use Wiki Maker to scaffold a new wiki, import sourced Markdown/JSON/Chronoscope content, inspect a graph, propose dated edits and review their effects.
---
To start a new wiki, run `wiki-maker scaffold` and `wiki-maker init`, then build reviewable proposals with `wiki-maker import` (`markdown`, `json`, or `chronoscope` adapters) or `wiki_propose`.
To update an existing wiki, run `wiki-maker find`, `wiki-maker graph`, or the `wiki_find` / `wiki_graph` MCP tools to locate the subject, then read it at the event date and the current knowledge cutoff. Check the original source and its publication date. Reuse existing source and event IDs. Give new claims a source, an article ID and the first date they apply. Express structured connections with typed `relations` (`powers`, `uses`, `part-of`, `chronicles`, `covered-in`, `implements`, `built-with`, `related`) and optional `entityType` and `homepage`. Keep inference and forecasts in editorial sections.
Use `wiki_propose` with the changes and a precise revision message. Inspect `wiki_preview`, including removed sources and intervals. Validate, then publish the reviewed proposal to the same local graph. A changed base requires a fresh diff. Check an earlier `knownAt` snapshot and the new snapshot. Export a new public site (with sharded history, search index, collection hubs, and Graph Explorer) from an empty directory.
